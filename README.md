# ac-deck

A controller-friendly launcher for the original Assetto Corsa on Steam Deck.

**Installation preview withdrawn on 3 November 2026. Do not use v0.1.0-preview.1.**
Its Pillow 12.2.0 dependency has applicable security advisories, including a
JPEG thumbnail issue affecting the launcher. The binary release has been
returned to draft and the install command is withheld while a corrected
preview is prepared. Its source tag and recorded hashes are retained; no
published file is silently replaced.

The correction updates Pillow to 13.0.0 and the SDK build dependency setuptools
to 84.1.0, followed by new source/package checks and corresponding dependency
sources. A new version will provide the public one-command installation.
