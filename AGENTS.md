# Community preview guidance

This branch contains the ac-deck presentation and interface previews. Runtime
source and a compiled candidate are prepared separately and await a first-party
license decision before public release.

Keep documentation concise, links relative and screenshots identified as real
renderer compositions with fictional authored content. Preserve their manifest
and provenance. Do not add private source history, credentials, player data,
game files, CSP, mod archives or unreviewed third-party media. Publication of
source code or a runtime package requires the remaining release prerequisites.

The product targets Steam Deck/SteamOS, using the original Assetto Corsa through
legitimate Steam/Proton integration. Screenshots and automated tests do not
establish physical Deck behavior or measured performance.
