# Contributing to the community preview

This branch currently publishes documentation and interface previews. A reviewed
source tree and a compiled community candidate are prepared locally; first-party
licensing and public package publication remain pending.

Useful contributions now include clearer documentation, broken-link fixes,
preview readability feedback and focused feature proposals. Use GitHub issues
with the affected screen, expected behavior, actual behavior and reproduction
steps. If reporting an existing launcher build, include its version and your
SteamOS/Proton versions. Keep API keys, account information and private paths
out of screenshots and logs.

Code contribution and build instructions will be published with the licensed
source release. Existing screenshots use the actual interface renderer and
fictional authored content; do not replace them with invented interface layouts
or unreviewed third-party media.
