# ac-deck interface previews

These ten images use the application's real SDL2 interface renderer on a
software surface, at 1280 × 800 and 1920 × 1200. The catalog is fictional and
the car/circuit schematics are original demonstration artwork. They contain
no game files, player data, album artwork or Toasty media.

The previews show interface composition; they do not show races or establish
Steam Deck performance. No game, window, microphone or paid API was started
to create them. A matching community candidate has been built and validated
locally. Source is available in this repository under [PolyForm Noncommercial
1.0.0](../../LICENSE). A runtime package is not published while bundled-library
LGPL review remains pending. Physical Steam Deck validation remains separate.

when the interface or branding changes. Source availability and packaging
